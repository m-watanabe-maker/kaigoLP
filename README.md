# 生成AI活用研修 実施報告LP

介護施設・医療事務クリニック・児童発達支援施設の3社で実施した生成AI活用研修の
アンケート結果をまとめた、社外にも見せられるランディングページです。

## 公開方法(GitHub Pages)

1. このリポジトリを GitHub にプッシュする
2. `Settings > Pages` で公開ブランチを指定する(例: `main` / `root`)
3. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## ファイル構成

- `index.html` — ページ本体(1ファイル完結、外部ファイル依存なし)

## 編集について

- 数値や受講者の声はアンケート原文に基づく実データです。差し替える場合は本文中の該当箇所を書き換えてください。
- フォントは Google Fonts(Zen Maru Gothic / Zen Kaku Gothic New)を読み込んでいます。
